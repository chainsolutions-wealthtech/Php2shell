PHP2SHELL

Analyse défensive PHP — prototype d'interface sans accès serveur

Prévisualisation locale uniquement · Aucun site n'est audité

1. Préparer un projet Web

Une URL publique ne donne pas accès au code source PHP du serveur. La vraie vérification nécessite un mandat validé.

Aucun appel réseau n'est réalisé par cette interface.

2. Conditions avant un audit réel

Identité, autorisation et consentement : non vérifiés
DNS / IP de destination, redirections et quotas : non vérifiés
Collecte passive des pages : non exécutée
Analyse PHP/SAPI et backports : non attestée
Rapport et passage PHPPATCH : à valider

Les prochaines étapes nécessitent une API authentifiée et le contrôle effectif des mandats MCP existants.
